## P0 — Fix first

**P0-1 · No payment path, but pages promise one.** There is no Stripe Payment Link anywhere on the live site. The old link (`buy.stripe.com/7sYf…`) survives only in HTML comments. Meanwhile `financing.html` (lines ~494/515/610) shows "Pay with Klarna →", "Pay with Afterpay →", "🔒 Go to Checkout →" that route to `checkout.html`, whose own CTA just says the Stripe link "is being prepared" and bounces to `/book.html`. A visitor who clicks "Pay with Klarna" expecting to pay hits a dead end.
→ **Decision needed:** either (a) create the $700 + $70/mo Stripe link and wire it into `checkout.html` + financing, or (b) relabel all "Pay / Checkout" copy to "Book a call to start" so the funnel reads honestly. Today it's a bait-and-switch.

**P0-2 · Homepage CLS = 0.217 (failing), sitewide root cause.** `urgency-banner.js` injects a fixed bar via `document.body.insertBefore(...)` *after* first paint, shoving content down. Every page that loads it fails CLS (`/` 0.217, `/checkout` 0.18, `/book` 0.156, `/financing` 0.288); the two pages without it are ~0.00.
→ **Fix once, fixes four pages:** reserve the banner height in the initial HTML/CSS (e.g. a top padding / `--vx-urgency-h` var) instead of measuring + injecting post-paint.

**P0-3 · Homepage LCP = 5.6s (was 3.1s).** The hero image (`hero-bg-ai-helpdesk-1440.webp`, only 66 KB) downloads fast but paints late: **render delay 2.87s (51% of LCP) + load delay 1.25s (22%)**. Cause is main-thread blocking — ~230 KB inline `<style>`/JSON-LD parse + GSAP/ScrollTrigger init running before paint — and the hero preload sitting *after* ~170 lines of JSON-LD in `<head>`.
→ **Fix:** move the hero-image preload to the very top of `<head>`; defer GSAP/ScrollTrigger init until after LCP (`requestIdleCallback`/after `load`); split the giant inline style so non-hero CSS doesn't block first paint.

## P1 — Important

**P1-1 · Pricing is inconsistent across the site.**
- Homepage / `checkout.html` / `financing.html`: **$700 / $900 / $1,200** build + **$70/mo** (growth add-ons $250 / $500 / $1,500). *Internally consistent — this is the current model.*
- `for-barbers.html`: **$3,500**, `priceRange "$1,500 – $12,000+"`, **$125/mo** (lines ~25, 566, 572, 678) — retired 4-tier model, in both visible copy **and** JSON-LD (rich-result risk: Google could show $3,500).
- `sms-opt-in.html`: budget dropdown **$1,500 / $3,500 / $6,000 / $12,000** (lines ~315–318) — retired tiers.
→ Update `for-barbers.html` and `sms-opt-in.html` to the $700/$70 model, or `noindex`/retire `for-barbers.html` if it's a legacy ad LP.

**P1-2 · `sms-opt-in.html` form is dead.** `<form id="optInForm" onsubmit="event.preventDefault();">` with a "Send My Request" submit button and **no JS handler** — captures nothing. This is the SMS-consent form a carrier/TCPA reviewer would test.
→ Wire it to the leads endpoint (mirror the homepage `bookingForm` → `…/leads`) or a Formspree/mailto fallback.

**P1-3 · Footer contrast fails WCAG AA, sitewide.** Gold footer links use `rgba(212,175,55,0.65)` → **4.47:1** on the near-black footer (needs 4.5:1); two grey sub-taglines are worse (`#74767c` 4.47:1, `#6d6e74` 4.0:1). Affects every legal/contact/social link on `/`, `/checkout`, `/financing` (shared footer).
→ Raise gold link alpha 0.65→~0.78 (or solid `#D4AF37` = 9.67:1); darken the grey taglines to ≥`#8a8c93`.

**P1-4 · `vs-logo-shield-clean.png` is a live 404.** Referenced by `for-barbers.html` as the nav logo (line ~589), `og:image` (line ~35 — also wrong shape: a logo, not a 1200×630 card), and the Organization JSON-LD `logo`. Existing good assets: `vs-logo-shield-512.webp` (200) and `og-social-card.jpg` (200, 1200×630).
→ Repoint the logo refs to `vs-logo-shield-512.webp` and the `og:image` to `og-social-card.jpg`. *(Note: the live homepage no longer references this file — #37 cleaned it up there — so this is scoped to `for-barbers.html` and any other page still pointing at it.)*

**P1-5 · `checkout.html` is in `sitemap.xml` but `<meta robots="noindex, follow">`.** Contradictory crawl signal; also drags its SEO score (69) into the audit.
→ Remove `checkout.html` from `sitemap.xml` (a conversion page should be noindexed and out of the sitemap).

**P1-6 · Homepage title/description format.** `<title>` = "Velonyx Systems — The Premium Platform Without the Premium Price" (67 chars, truncates in SERP); meta description is **263 chars** (badly over the ~155 SERP limit). Several other pages append "| Your Legacy, Engineered With Precision." pushing titles to 77–84 chars.
→ Trim titles to ~55–60 (drop the motto suffix from `<title>`, keep it on-page); cut the homepage description to ~150–160.
